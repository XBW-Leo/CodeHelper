请对以下范围做行为不变的重构：$ARGUMENTS

先加载并遵循 `refactor` skill（`.pi/skills/refactor/SKILL.md`）的流程：

1. **理解现状**：通读目标代码及其调用方。
2. **建立基线**：运行现有测试 / 校验，确认全绿后记录基线。
3. **出方案**：输出目标结构、实施步骤、影响面、风险；除非我在指令中明确说"直接做"，否则停在方案阶段等待确认。
4. **小步实施**：一次一步，每步后运行测试；实施前用 git 记录状态。
5. **回归验证**：运行与基线相同的测试 / 校验，全部通过。
6. **报告**：改动内容、涉及文件、验证结果、行为变化（如有）。

规则：行为不变，不顺手加功能或修无关 bug；保持 API 兼容；改动最小。

推荐模型档位：heavy（pro 级推理）。
