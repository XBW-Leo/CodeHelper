---
description: 对改动或指定代码做结构化代码审查，只审查不修改
argument-hint: "[范围，默认 staged/未提交改动]"
---
请对代码改动进行结构化审查。范围：${@:-当前 git 暂存与未提交的改动}

步骤：
1. 确定审查范围：默认 `git diff` 与 `git diff --cached`；可用 $1 指定文件、目录或 commit 范围。
2. 通读相关代码及其调用方，不要只看 diff 片段；必要时运行只读命令验证行为。
3. 按以下结构输出：
   - 概览：改动意图与影响面
   - 优点：做得好的地方
   - 问题：bug、安全隐患、错误处理缺口、性能与可维护性风险
   - 测试：覆盖情况与缺失
   - 建议：按优先级排序的具体修改建议
4. 只审查，不修改代码，除非我明确要求。
